# Training Protocols

The repository supports two distinct training protocols. Do not compare or
describe them without naming the protocol explicitly.

## `schedule_aware_legacy`

- Reproduces the 2026-08-11 seven-rule runs.
- Training trajectories are generated by ECC, Binary, CW-ABCD, Unigram,
  Atomic-KGW50, Atomic-KGW25, and Entropy-KGW request processes.
- The adapter receives only the current target-set summary, not a watermark
  identity, detector, codeword identity, or key identity.
- Valid claim: shared process-aware adaptation across representative request
  families.
- Invalid claim: schedule-independent or unseen-schedule generalization.

## `composition_pool_corrected`

- Training receives no watermark schedule.
- It canonically enumerates every 2-, 4-, 7-, and 8-of-16 atom union before
  repetition, covering all 26,250 unions.
- ECC, Binary, CW-ABCD, Unigram, Atomic-KGW50, Atomic-KGW25, and Entropy-KGW
  are attached only at held-out evaluation.
- Valid claim: schedule-independent transfer over the evaluated target-set
  geometries.

The shared implementation is `run_experiment.py`; the protocol is selected by
the mandatory launcher flag `--training-protocol`. Protocol-specific launchers
live in the two subdirectories below.
